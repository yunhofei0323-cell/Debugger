 # American Sign Language Letter Recognition
## A CNN-Based Real-Time System
### From Team Debugger

This ia a real-time system for recognizing American Sign Language letters based on convolutional neural networks.

## Project Purpose 
The purpose of this project is to build a real-time system to recognise American Sign Language letters, 
so as to bridge communication barriers between sign-language users and ordinary people. 
We explore a feasible CNN solution for gesture recognition,
and lay a foundation for future sign-language translation applications.

## Project Overview
This project builds a complete workflow for American Sign Language letter recognition.
The whole pipeline includes dataset construction, image pre-processing, CNN model training,
classification correction and real-time camera deployment.

## Workflow
1. Problem definition for ASL letter recognition
2. Dataset collection and sorting
3. Image grayscale conversion and pre-processing
4. CNN model training
5. Secondary classifier for improved accuracy
6. Real-time prediction through webcam

## Main Features
- Real-time gesture recognition from webcam
- CNN image classification model
- Optimised image pre-processing steps
- Lightweight structure for simple deployment

## Project Limitations & Future Work
There is still room to improve pre-processing methods and neural network design.
Future work may expand the dataset and optimise recognition accuracy in complex backgrounds.
